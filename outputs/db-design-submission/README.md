# ERD·데이터베이스 정의서 제출 자료

- `프로젝트_데이터베이스_정의서.xlsx`: 프로젝트 개요, 요구사항, 26개 테이블, 117개 컬럼, 33개 FK 관계, 제약조건, BR01~20, 고도화·시연 시나리오를 담은 8개 시트.
- `01_통합_ERD.png`: 전체 속성을 표시한 통합 ERD. 원본 해상도 4260×2740. IE 표기, PostgreSQL 기준.
- `02_사원_프로젝트_ERD.png`: 사원·권한·기술·프로젝트·직무수행이력·경쟁 관계 상세.
- `03_평가_ERD.png`: 고객·PM·동료 평가 상세.
- `04_휴가_ERD.png`: 휴가 정책·신청·부여·사용 상세.

통합 PNG를 기본 제출 이미지로 사용하고, 상세 PNG 3개는 함께 첨부하면 확대 없이 영역별로 확인하기 좋습니다. 정의서의 조명·조원 칸은 실제 팀 정보가 제공되지 않아 미기재로 두었습니다. 제출 전 해당 칸을 입력하세요.

정의서는 저장소의 V1 DDL·모델·업무 규칙·요구사항·시나리오를 기준으로 작성했습니다. 날짜·시간 타입은 실제 PostgreSQL 스키마의 DATE/TIMESTAMP를 사용하며, 논리 모델의 DATETIME 표기를 물리 타입으로 그대로 복사하지 않았습니다. 기존 스키마와 관계 정의는 변경하지 않았습니다.

휴가와 정보 차단벽의 업무 고도화 방안을 포함하고, 현재 구현 범위와 후속 구현·성능 실험 계획을 구분했습니다. 미정인 평가 점수 척도는 임의로 확정하지 않았습니다. 이후 단계의 별도 SQL 제출 요구는 이 엑셀 파일로 대체하지 않습니다.
